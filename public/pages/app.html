¿Por qué usar nuestro Recetario?

El Recetario de Gastronomía es una aplicación web diseñada para almacenar, gestionar y organizar recetas culinarias. Permite agregar, editar y eliminar recetas, facilitando el acceso y la administración de ingredientes y procedimientos.

Acceso rápido y organizado

Encuentra tus recetas en segundos gracias a su estructura categorizada.

Guarda tus recetas en la nube

Próximamente, almacenamiento en línea para acceder a tus recetas desde cualquier dispositivo

Actualizaciones constantes

Planeamos agregar nuevas funciones para mejorar el sistema continuamente.

Tecnologías
Utilizadas

Frontend

  • HTML y CSS para la estructura y diseño.
  • JavaScript (Alpine.js) para la manipulación dinámica de datos.

    • Backend

  • PHP para la gestión de datos y conexión con la base de datos.
  • Base de datos en la nube para almacenar recetas de manera persistente.

    • Futuras Mejoras

  • Implementación de autenticación de usuarios.
  • Integración con una API de ingredientes para sugerencias.
  • Mejora en la interfaz de usuario con animaciones y diseño responsivo.
  • Funcionalidad de búsqueda avanzada para encontrar recetas más rápido.
  • Creación de una comunidad donde los usuarios puedan compartir y calificar recetas.

    • Nuestra aplicación wed esta en desarrollo por lo que esta no es una versión final y recibirá actualizaciones constantemente
